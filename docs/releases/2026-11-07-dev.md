## Delivered

## Remaining correctness issue and limits

**#117 must be addressed before production validation of manual template phase
edits.** A fixed ribs cooking start with an explicit allowance can wrongly serialize
in-phase checkpoints and over-delay serving. This existing bug is medium severity;
no actual timestamps or records were observed to be lost or changed. Default
brisket/ribs serving alignment works. See the focused reproduction in
[#117](https://github.com/Warconn/how-many-beers/issues/117).

Shared-smoker preheating, capacity and temperature coordination remain #3; generic
Smoker/Pellet smoker labels do not prove one physical device. Alarms/notifications
remain #11. Recipe libraries, URL import, social login, paid features and advanced
sync remain deferred. Stale docs PR #106 was closed without merging its old queue.
Do not treat delivered #109/#101/#61/#83 work as new implementation.
